Purpose of the App: 
Finance Flex is a fitness-inspired personal finance management application designed to help users track their income, expenses, receipts and financial goals. The application aims to improve financial awareness by providing users with clear insights into their spending habits and financial performance. Through features such as transaction tracking, budget goals, receipt management, and financial reports, users can make informed decisions and work towards achieving better financial health.

Own Features: 
Two unique features were developed to distinguish Finance Flex from traditional budgeting applications. The first is the Financial Fitness Score which evaluates a user's financial behaviour based on factors such as spending patterns, income, budgeting and transaction activity. This score provides users with a simple way to measure their overall financial wellness. The second feature is the Workout Challenges system which introduces gamification into financial management. Users can complete challenges such as staying within a spending limit, logging a certain number of transactions or attaching receipts to purchases. These challenges encourage positive financial habits and increase user engagement with the application.

Design Considerations: 
The design of Finance Flex was guided by usability, accessibility and user engagement principles. A fitness-inspired theme was chosen to reinforce the concept of improving financial health in the same way people improve physical fitness. The interface uses clear navigation through a bottom navigation bar, concise dashboard summaries, visual charts and progress indicators to help users quickly understand their financial status. Consistent colours, readable typography and intuitive layouts were implemented to ensure a positive user experience for both new and returning users.
